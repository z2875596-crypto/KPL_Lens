# KPL Lens · KPL 导播挑战 0.13

在线试玩：https://z2875596-crypto.github.io/KPL_Lens/ （手机建议横屏）

GitHub Actions 会在 `main` 更新后运行测试、构建并发布 GitHub Pages。游戏在浏览器本地运行，无需登录。

采用 AI 绘制 Q 版同人素材的非官方粉丝 H5 游戏。React + TypeScript + Vite + PixiJS。

## 启动与验证

```sh
npm install
npm run dev
npm test
npm run build
```

打开终端输出的本地地址。正常对局 180 秒；欢迎页另有 22 秒团战、反杀、暴君争夺、主宰争夺和双线取舍演练。

## 镜头操作

- 点击任意英雄头像跟拍；英雄阵亡后留在现场，复活不自动恢复跟拍。
- 点击或拖动小地图定位，拖动主画面或按方向键自由移镜。
- 滚轮、± 或按钮选择近景／标准／广角；切换目标保留景别。
- 1／2／3 定位三路，龙坑按钮定位资源区。这些快捷键只定位固定区域，不预知事件。
- E 打开十人经济面板，显示血量、位置、KDA 和经济；点击一行跟拍。打开面板时比赛继续。
- B 开关弹幕；空格暂停；切出页面自动暂停。展开全图时暂停。

## 评分与观众

评分使用与画面一致的实际镜头范围，检查关键人物是否入镜。提前持续观察至少 1.2 秒、拍到交锋并留住结果可获得完整捕捉；仅拍到交锋算有效捕捉，晚到只奖励结果。广角拍小规模战斗降低细节奖励。

镜头完成度按完整 100%、有效 80%、补到结果 30%、漏拍 0% 取平均。同期拍到较重要的事件时，较小事件漏拍标记为合理取舍，不扣分、不清连击、不计入平均值。双线取舍演练可验证此规则。

漏拍普通事件扣 50，重大事件扣 200 并清连击；分数最低为 0。两秒内超过三次切镜扣 20。弹幕在事件判定后反馈，支持夸奖、吐槽和取舍理解，不提前泄露事件；暂停时弹幕同步暂停。结算页提供文字复盘及 PNG 成绩卡。

## 战场和赛事界面

- 统一峡谷含三路、河道、野区、草丛、龙坑、防御塔和水晶；五套原创 Q 版角色表现团战、反杀与抢龙。
- 顶部展示当局击杀数、双方经济、暴君数、BO3 小局胜场。两侧固定十人血条、掉血残影、个人经济、区域和复活倒计时。
- 正常比赛胜方增加一局，先到两局获胜；下一局保留比分，新系列赛清零。演练不计入小局比分。
- 经济包括每秒 18 基础收入、击杀 300、助攻 50、暴君每人 100。胜负优先按水晶结果，否则比较经济，再使用最后事件胜方决胜。

## 实现与范围

`engine.ts` 以 30Hz 固定步长更新统一世界；`camera.ts` 管理镜头；`director.ts` 负责空间评分和弹幕；`render.ts` 渲染共享世界；`main.tsx` 管理界面和流程。

战斗仍是带种子的脚本化模拟，镜头不影响世界更新。防御塔和营地尚无完整塔伤、独立野怪 AI 或碰撞寻路。不接入真实 KPL 数据、不使用官方英雄美术；暂无账号、在线排名或对局录像。系列赛保存在当前页面会话中。

## 战斗表现 0.5

- 移动使用加减速与近距离分散，后排保留更大距离；施法前摇阶段减速，攻击有前摇、释放、命中与恢复四个视觉阶段。
- 五种职业采用不同攻击节奏与刀光、枪芒、扇形弹道、箭矢、重击表现；突进拖尾、命中火花和关键事件冲击环增强反馈。
- 抢龙打野在结算前连续突进龙坑，取消结算瞬移；反杀操作者提前开盾并回身突进。
- 关键事件后，操作者获得金色标记和姓名／动作标签，转播标题同步注明操作者。标记跟随真实英雄坐标，不自动移动导播镜头。
- 仍为脚本化战斗，常规血量消耗与结局由事件编排驱动，尚非逐技能伤害计算系统。

## 地图与回复规则 0.6

小地图常驻左下导播操作区，独立于直播画面。直接点按定位、拖动连续移镜，金色框表示镜头范围；手机横屏地图本体高 150 像素。

野外不再被动快速回血，事件脚本只能降低现有血量。低于 35% 血量且交锋结束的英雄撤退 2.5 秒、回城读条 3 秒，回到泉水后每秒恢复 25% 血量，满血重新出发。阵亡英雄在基地复活；两侧状态栏显示撤退、回城和泉水恢复。此为简化的回城流程，尚未模拟技能打断回城。

## 手机横屏布局 0.7

横屏低高度设备采用左侧地图与景别按钮、右侧比赛的布局，取消底部大控制台。对局中隐藏导播统计和区域快捷键，成绩仍在结算页展示。844×390 下比赛区域高约 306px，地图本体约 158px；桌面及竖屏保留原布局。

## Q 版界面与战况提示 0.8

统一蓝绿／珊瑚红配色、圆角面板、放大的Q版头像，保持主画面和小地图布局尺寸。实际攻击释放或血量减少后显示交战标记，停止后 1 秒淡出；0.8 秒内损失至少 18 个血量百分点时显示累计损血，持续 0.9 秒，同一英雄两次提示至少间隔 1.6 秒。纯观察模块不接收事件安排，不预告高光、不改变英雄顺序。暂停时提示随模拟时间保持。

## 团战辨识度 0.9

前后排采用错开纵向站位，并增大近距离分散范围。普通角色缩小以留出轮廓间隙，跟拍角色略大且置于人物最上层，配金色脚环、头顶箭头及跟拍姓名。普通技能位于人物下层，按蓝红双方着色，削减刀光宽度和命中粒子。布局与摄像机判定范围不变。

真实英雄形象参考入口：https://pvp.qq.com/web201605/herolist.shtml 。现已接入 AI 绘制的英雄 Q 版同人素材，并非官方游戏资源。

## 英雄形象试装 0.10

透明角色图集位于 public/heroes/chibi-atlas-v1.png，战场全身像与两侧头像共享素材。英雄池包含镜、公孙离、女娲、司空震、苏烈、关羽、赵云、蒙恬、敖隐、钟馗、小乔；每局十人，蓝方对抗路在司空震与蒙恬之间按局轮换。阵营依靠脚环和血条区分，保留跟拍强调，不改变手机布局。

当前为静态精灵配合程序控制的移动、朝向、起伏与出招摆动；仍使用职业级技能表现及脚本战斗，尚未逐英雄还原技能机制或制作逐帧动画。


## 三位英雄专属技能表现 0.11

镜：银蓝镜像场、半透明镜像和镜片；公孙离：原地留伞、侧移与回伞；关羽：定向冲锋、青绿刀弧与蹄迹。技能从当前攻击释放与有效近敌触发，使用固定施法起点、独立冷却和最多 1.25 秒的视觉生命周期；死亡、脱战或回城取消。镜像不增加血条或可选单位，技能名仅在跟拍时短暂显示。移除根据未来事件提前出现的团战／龙坑光圈，专属技能期间不叠加通用攻击粒子。手机布局不变。

这是基于官方英雄介绍的简化动作与特效，不是完整技能数值系统：伤害和击杀仍由原战斗脚本决定，不新增野外回血、镜像伤害、控制或真实冷却还原。

## 全英雄技能与 Q 版野怪 0.12

补齐女娲矩阵、司空震雷电、苏烈柱击、赵云枪落、蒙恬盾阵、敖隐三束龙焰、钟馗钩链、小乔回旋扇。共 11 个独立签名技能。屏内最多突出三组完整特效，跟拍英雄优先；其他施法者用低透明度的紧凑标记保留反馈。所有技能继续使用当前施法状态触发，不读取未来事件，不额外改变脚本伤害或治疗。

画布渲染密度改为 2–3 倍，图集开启缩小层级采样；角色基准高度由 68 调至 76 世界单位并上移血条，布局与镜头判定范围不变。此项改善采样与轮廓可见度，不意味着已重绘原英雄细节。

新增透明 Q 版蓝红 Buff、野猪、河道小怪、紫色主宰和金色暴君素材，带轻微呼吸动态。主宰位于新地图坑位，暂不参与争夺结算；已有暴君的掉血、击杀消失和重生表现继续联动。素材及完整提示词见 art/monsters-generation.md。

## 野区战斗与双龙争夺 0.13

野怪共享独立血量、受击时间、最后一击操作者、伤害贡献和重生计时。空闲打野与射手会前往存活的野怪，进入射程并实际出招后才能扣血；野怪反击会减少英雄血量，死亡只发放一次 65 金币奖励，14 秒后重生。野怪反击暂不致死，残血英雄沿用既有回城流程。

主宰与暴君分别参与争夺并独立计数，18 秒重生。双方根据演练节奏靠近龙坑，最后一击由实际存活、射程内的英雄完成，近身惩击有独立冷却；结束时才写入实际阵营、操作者与是否抢夺（另一阵营此前造成更多伤害）。团队奖励每人 100 金币，仅结算一次。常规对局避免安排尚未重生的同类龙；菜单增加主宰演练。

双龙的血量来自真实攻击累计，不再随事件倒计时自动下降；高光标题、脚环、光柱及弹幕只在目标死亡后触发。评分等待实际结束，不对尚未发生的争夺结算。仍是简化模拟：争夺时机与行进意图有脚本编排，不包含完整 MOBA 技能数值、野怪仇恨／拉脱和主宰先锋兵线机制。
